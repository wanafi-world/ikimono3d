# いきもの採集 3D

iPadで遊べる、いきもの採集の3Dゲームです。

- 遊ぶ：GitHub Pages のURLを Safari で開き、「共有」→「ホーム画面に追加」で全画面のアプリとして遊べます。
- セーブ：はじめに「家族のあいことば」を入れると、Firebase Realtime Database に名前ごとに保存され、同じあいことばの端末どうしで共有されます。協力プレイの通信も同じしくみです。
- 設定：`firebase-config.js` に Firebase の設定を入れます。
- 写真のクレジットはゲームの図鑑の中にあります（iNaturalist の公開データ・写真AC）。恐竜とUMAの絵はAIで作った画像です。
